# 合成示例

本项目区分三类材料：

| 材料 | 用途 | 能否直接作为数据库导入文件 |
|---|---|---|
| `backend/app/seed/demo.py` | 通过业务模型和事务生成完整模拟场景 | 通过案例 seed 入口运行，不作为文件导入 |
| `backend/app/llm/eval/golden/jd_golden.jsonl` | 构造的岗位解析评估样本，金标为作者构造真值 | 不是学生或岗位批量导入格式 |
| 服务端导入模板 | 按具体导入类型展示列与样例 | 需遵循对应 API 的字段及权限契约 |

首版示例不包含真实学生资料、实际联系方式或企业业务库。账号密码由独立部署入口随机生成。种子的默认行为是拒绝二次写入，新案例不提供覆盖已有数据的 reset 命令。

运行步骤见 [部署说明](../docs/deployment.md)。只有真实 PostgreSQL 执行与回读通过，才可声称这一版本的种子生成得到验证。

# 已知限制

1. 本版本是工程参考案例，未完成生产交付验收。
2. 四个管理页面的源码、构建和浏览器验收是不同证据，具体结果逐项记录在 verification.md。
3. 导入、招聘会、访企、场景、报表及门户保留现存后端实现；不能据此推断管理界面或整个业务流程完整。
4. 学生前端与完整离线包缺少必要构建输入，不承诺全套重建。
5. provider 单元测试使用构造实现，真实模型推理、模型效果与嵌入质量未因此得到验证。
6. 历史 PostgreSQL 记录中的 22 项实际通过与 32 项期望差异判定不能合计为 54 项实际通过，也不能替代本版本测试。
7. 首次安装需联网下载依赖与镜像；本仓库不附带离线镜像、模型权重或业务数据。
8. 依赖保留部分不适用于当前调用路径的已知公告，适用分析见 dependencies.md。更改功能或依赖使用方式后需要重新评估。
9. 新部署入口拒绝接管已有资源，没有自动 reset 或数据删除功能；失败实例需按证据处理。

# 案例范围

首版定位是现存工程的可审查封装。必要修订围绕公开去敏、依赖一致性、配置边界、测试凭据和独立部署展开。

## 保留

- 管理端登录、驾驶舱、画像、帮扶、岗位页面。
- 完整现存后端应用、Alembic 迁移和测试，包含导入、招聘会、场景、访企、报表及门户相关实现。
- 确定性规则、模型接口、合成种子和构造的岗位评估样本。
- 中文说明、依赖与许可证据、验证结果及失败/未验证状态。

## 当前缺口

学生前端的 package.json 与锁文件，以及完整离线包和部分历史运行检查脚本不在可用输入中。首版不承诺重建这些缺失交付物。旧版本的镜像、模型、数据库和恢复材料属于私人封存，不属于本公开版本。

原工程需求文档与恢复记录没有随仓库公开。源文件中的历史阶段注释仅帮助追踪实现，不表示该阶段已在本版本验收。

## 首版接受标准

公开集合经过逐文件审查，不含可用凭据或私人数据；依赖安装与锁文件一致；自有代码公开权利已确认，第三方许可与残余公告明确说明。测试不删除失败断言，不把跳过或未执行计为通过。部署声明以实际验证结果为限。
